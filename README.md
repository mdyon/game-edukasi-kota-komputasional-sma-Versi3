# Kota Informatika SMA V3
Game edukasi eksplorasi 2D top-down untuk Informatika SMA.

Kontrol: WASD/panah, E/INTERAKSI. Di HP gunakan D-pad.

GitHub Pages: buat repository publik, upload semua file dengan `index.html` di root, lalu Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save. URL: `https://USERNAME.github.io/NAMA-REPO/`.

Game bersifat statis HTML/CSS/JS dan menyimpan progres di localStorage.
